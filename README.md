# 🌳 二叉树可视化分析器

一个基于 **HTML + CSS + JavaScript** 的网页可视化程序，用于直观理解二叉树的结构、遍历和性质。

## 📋 功能列表

### 1. 二叉树的创建
- 支持**层序输入法**创建二叉树
- 使用 `null` 表示空节点
- 支持多种输入格式：`[8,4,12]`、`8,4,12`、`8 4 12`
- 内置多个预设示例（一键填充）

### 2. 二叉树的基本遍历
| 遍历方式 | 递归版 | 非递归版 |
|---------|--------|----------|
| 前序遍历 | ✅ | ✅ |
| 中序遍历 | ✅ | ✅ |
| 后序遍历 | ✅ | ✅ |
| 层序遍历 | ✅ | - |

### 3. 结构分析
- 节点总数
- 叶子节点数量
- 树的高度
- 每一层的节点数量
- 最宽的一层宽度

### 4. 性质判断
- 是否为空树
- 是否为满二叉树
- 是否为完全二叉树
- 是否为平衡二叉树
- 是否为二叉搜索树（BST）

### 5. 路径相关功能
- 查找指定值是否存在
- 输出从根节点到目标节点的路径
- 输出目标节点所在的层数

### 6. 可视化输出
- **图形可视化**：使用 Canvas 绘制二叉树结构图
- **文本可视化**：以字符画形式打印二叉树

## 🚀 使用方法

1. 直接用浏览器打开 `二叉树可视化分析器.html` 文件
2. 在左侧输入框中输入层序数据（或点击预设按钮）
3. 点击「🚀 创建二叉树」按钮
4. 查看右侧的分析结果和可视化图形

## 📝 示例输入

```
[8, 4, 12, 2, 6, 10, 14, null, null, 5, 7]
```

表示的二叉树：
```
        8
      /   \
     4     12
    / \    / \
   2   6  10  14
      / \
     5   7
```
